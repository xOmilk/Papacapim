# 🐦 Papacapim


## 📱 Download e Instalação (Android)

Para testar o aplicativo diretamente no seu celular Android, baixe a versão de desenvolvimento mais recente gerada automaticamente:

[![Baixar APK](https://img.shields.io/badge/Baixar-APK_Android-green?style=for-the-badge&logo=android)](https://github.com/xOmilk/Papacapim/releases/latest/download/app-release.apk)


### Passo a passo de instalação do App:
1. Pelo seu celular, clique no botão verde acima para baixar o arquivo `app-release.apk`.
2. Após o fim do download, clique em **Abrir**.
3. O Android avisará que o aplicativo vem de uma fonte desconhecida. Isso é normal para apps em fase de testes.
4. Clique em **Configurações** no alerta que aparecer e ative a opção **Permitir desta fonte**.
5. Volte para a tela anterior e clique em **Instalar**.
6. Pronto! O aplicativo já pode ser aberto e testado.
